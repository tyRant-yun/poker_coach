## 2. 交付边界

T1 包含 LP-A@1、LP-B@1 两个概念演示包。每包核心阶段可完成，有两个受控对照、一个反例、一段实际连续决策、三道迁移候选与一题本地延迟候选。题目未见身份由暴露判断，不要求每位用户始终能得到三道新题。

教学目标为条件识别、范围来源、Hero 与范围联系、事实/假说/示意值的区别及迁移过程。两个包均不提供真实 GTO 动作评分或教学有效性声明；EV 仅保留原研究页的配对合成展示。概念题和结构校验真实工作，预测、修订和数据恢复真实保存。

不做完整内容 CMS、任意翻前树、多桌计时训练、完整摊牌模拟、真实能力模型或外部提醒。内容检查器必须可用，不能以空页面替代；内置内容以显式资产编写与校验发布。

知识库新增范围：24 主题/至少 96 个概念索引、至少 36 条可核对原子主张、12 份精确定位来源（至少 3 个独立来源主体）、8 组误解/条件反例、18 个检索验收问题。先保证两包每条解释有完整依据；其余领域显示缺口，不宣称已建成全部理论正文。运行时检索、引用和导入真实工作，联网采集/LLM 提炼继续使用明确过程样例，不接真实在线知识服务。

## 3. 执行安排：以完整旅程连续推进

用户之后授权 T1 开发时，默认目标为同次完成下列整个批次；内部检查点不增加逐任务用户确认，不自动在 LP-A 后结束。若实际无法继续，保存可运行成果和明确未完成项，不将单包写成整轮完成。

| 内部工作包 | 首个用户可见闭环 | 涉及任务 |
|---|---|---|
| P1 LP-A 与必要底座 | 首页→翻前课程→预测→来源/主张查询→范围/对照/反例→连续片段→总结→迁移/复测 | TE01/02/03/04/05；TE09 的首批引用与检索；TE08 底座前移 |
| P2 LP-B 与学习工具 | 近邻/后续牌→知识条件与反例→实际片段→迁移；Agent 使用真实检索/引用，复盘有相关成果 | TE06/07、第二包基础；TE09 理论目录与知识构建闭环 |
| P3 内容与整合 | 内容/知识检查→版本/冲突/缺依赖→导出/重置/导入→旧版兼容→整轮演示 | TE08/09 剩余工作及全部旅程回归 |

同一工厂或底座可分次完善，但每包先有可操作旅程，不先铺满导航/数据层。必要验证通过后保存提交并继续；最后统一构建和受影响的旧回归。不为文档设计反复运行应用测试。

## 4. TE01：内容包与教学资格

依赖：本轮设计。产物：两包 manifest/资产/题目/答案/解释/政策、校验器、只读查询；目录入口与内容身份显示。

必须实现：

- 将内容规格中的每个 ID 落为明确对象，写入版本/哈希/依赖和 target/given scope；不用旧索引生成频率或类别代替。
- 建立概念示例、流程示例和未来真实解的身份边界；实际本轮只允许前两种。
- 完成两包固定事实与所有显式分配/金额的自检，记录“作者自检、未独立审核”，不伪签专家或外部审核。
- 内容预检能定位死牌、概率、账本、丢失引用、题目答案混放、重复 ID 和分类重叠问题；发布失败保留草稿。

验收：两个包的必需资产清单无缺项；无证据的数字不获得战略解释资格；故意损坏一项有具体反馈，不能进入正常教学；所有相关 UI 均读取应用查询。

## 5. TE02：课程运行与低负担策略作品

依赖：TE01 首个包与 TE08 必要持久化。产物：/learn、run 页面、阶段命令、Prediction/Attempt、局部编辑与总结。

验收：

1. 从 Hero 预测开始，无需填写完整范围即可完成指定 3–6 组合作品。
2. 给定/用户/参考有独立来源，目标外组合不算漏填；空值与 0 分开。
3. 先提交后看证据；直接看证据保存 skip/辅助而非编造预测。理由和信心可空或不确定。
4. 原预测、修订及总结可并排查看，重新开始创建新 run；刷新恢复当前版本和阶段。
5. 1440/1280/1024 的主操作、牌面、键盘选择、抽屉关闭/焦点恢复可用。

## 6. TE03：翻前核心路径与发现性

依赖：TE01 的 LP-A，TE02 第一条 run。产物：A-P0/P1/P2/P3、三条匹配翻后入口、投入/范围来源、库筛选与 PF02 修复。

验收：

- Open/BB Call、Open/3-bet/BTN Call、Open/3-bet/4-bet/BB Call 三条路径能操作，底池/剩余/跟注增量/动作集合跟着输入切换。
- 示例终局区分未结算投入、未跟注退还和实际结算底池，不把毛底池当净赢利。
- 每个后续范围能追溯固定初始范围和本玩家的行动权重；明确单玩家简化、未算 matchups。
- 用户改为其他尺寸或无 fixture 条件后保留输入，返回未覆盖；未提供动作不标“规则不合法”。
- 路径结束保持实际用户动作；在 Fold 后不能出现虚构未来翻牌。
- 库页面可按翻前/翻牌/转牌/河牌及形式筛选，当前标签与结果一致；S08 仍明确预览，LP-A 入口清楚。

## 7. TE04：多维评价与解释证据

依赖：题目、作品与固定输入。产物：T1-EP01、EvaluationArtifact、反馈卡片、证据跳转。

验收：目标范围结构、事实答案、作者分布对照、文本待审阅和不可用战略 EV 分开呈现。只对已声明目标集评分；未知和零严格区分。相同动作分组/单位/条件才允许对应比较。

频率距离用固定权重的 TV 定义，测试包含全相同、完全不同、权重变化、缺分配、零权重及不同动作映射。反馈引用固定 Attempt/输入/内容/规则；修改课程或规则不改旧结果。低频动作不因“不是最高频”一律判错，不能把自由文本关键词命中称为理解判定。

## 8. TE05：暴露、迁移与本地复测

依赖：TE02/TE04；暴露查询在任何答案消费者接入前完成。产物：语义暴露键、辅助事务、安全投影、选题和 ReviewItem。

验收：

1. UI、研究/知识链接、Agent、内容检查和导出都遵守同一信息边界。提示/暴露先登记，再返回目标答案。
2. 课程改名、导入复制、相同内容换包/评分版本不能获得新题身份；A/B 共享事实暴露可关联。
3. 首次 Attempt 提交后不可变；后来反馈不倒改首次身份；修订和另行重测分别标记。
4. 三题池按规则选取，耗尽给 POOL_EXHAUSTED；无历史/内存模式不记成确证未见。
5. 默认 24h 后排一项本地复测；用假时钟验证到期，提前 preview 不完成真实 ReviewItem。
6. “本次无辅助/本工作区暴露/原题或迁移或延迟”三维可读，不展示未经证据支持的 mastery。

## 9. TE06：对照、反例与连续决策

依赖：两包内容与范围/投影。产物：LP-B 完整课、实验作品、片段运行、两种统计分母。

验收：每包两对照一反例均可进入并保存预测/观察/结论。自变量、由其引起的派生差异和不允许变化的条件有清单；不满足对照规格时阻止定量比较。LP-B 后门/听牌事实正确，缺乏数值依据时可明确结论不足。

局部类别点击与行动点击显示不同分母，重叠不凑成 100%。连续片段真的记录多个节点，测验结束前无答案/未来泄露，未覆盖或弃牌按真实路径结束。不能将总频率相同视为策略组成相同或 EV 相同。

## 10. TE07：教学 Agent 与复盘衔接

依赖：TE02/05 的投影、TE06 证据与 TE09 检索/引用契约。产物：四个透明教学意图、实际 RetrievalRecord/CitationBundle 及带引用的 trace、复盘课程匹配入口。

验收：输入解释不泄露题目，针对提示使本次辅助；提交后解释能打开当前固定证据，不匹配则明确缺失。Agent 可建实验或本地复习项，但不会代填独立题、凭空登记成功或判定 mastery。

理论解释先查知识库、核对条件和证据资格，再逐主张组装引用；相关链接不能替代支持依据。无来源、冲突或条件不足时有正式状态，不能凭空产生“已引用”的解释。

复盘严格匹配输入才推荐对应课程，未匹配保留研究，不换牌面冒充；原文不改写。原三种研究 Agent 脚本仍工作；预算/暂停/取消/刷新恢复/重试无重复副作用。

## 11. TE08：内容检查、迁移恢复与整体验证

依赖：随着前序消费者交付，不留到最后重构状态。产物：新库/schema2 适配、schema1 迁移、内容检查器、完整导出导入、缺依赖/损坏恢复、文档。

验收：

- 按领域合同新库读写，迁移旧库时原件不变；无重复复制，损坏新库不静默回退旧状态。
- 导出/重置/导入可恢复 run、阶段、作品、内容/政策、暴露、评价、Agent trace 和复习关系；导入复制不制造新题身份。
- 内容自报审核不升级可信等级；缺版本/哈希不匹配先只读或拒绝，不套当前答案。
- 明确重置仅处理两个本应用库和本应用偏好，其他 localStorage/IndexedDB 不受影响。
- 内容版本升级保留旧课可读；停用版本不再用于新 run，不强改旧 Attempt。
- 知识主张/来源定位/索引/检索记录/引用束随导入导出和版本保存；原 K01–K08 的旧引用不被新知识内容强行改写。
- 阅读/启动/演示/旧版回看和新旧浏览器数据边界有准确说明；只记录实际验证和未覆盖项。

## 11.1 TE09：理论查找、知识库建设与教学引用

依赖：知识库设计及 TE01 内容身份；先于两包的引用消费者落实核心模型，不在 TE07 完成后补链接。产物：理论主题/概念图、研究任务、来源/定位/主张/关系、发布校验、本地索引、理论库 UI 和知识建设看板。

验收：

1. 范围数量和两包全部引用达到第 2 节/知识设计要求，目录、已读、已核对、可用于演示及 gap 分开；仅书目不计正文覆盖。
2. 能从研究问题登记来源、导入自写草稿、附定位、核对条件/反例、发布不可变版本、更新索引、检索并引用；联网步骤标为模拟，实际本地步骤有真实状态与成果。
3. 原子主张有类型/适用条件/例外、精确出处和实际审核身份；不靠自报“审核通过”或相似度升级可信度。
4. 中英别名、概念/主题、局面过滤可查，保留候选和排除原因；返回 match/conflict/insufficient-context/general-background；不会把 ICM/HU 特例无条件用于现金/多人局。
5. Agent 每条引用能打开其 claim 的来源位置和支持状态，不能把背景文献当本地示意频率的数值证明；引用校验检查已核对关系，不宣称自动证明自然语言真值。
6. 来源变更/撤回、链接不可达、定义冲突、没有结果、缺定位均可演示；旧评价仍引用旧知识版，不能被新版静默替换。
7. 知识搜索结果标题/摘要、正文、外部整篇来源和导出遵守暴露/提示规则，不通过知识检索绕过独立题。
8. 至少 18 个固定检索案例组合验证相关性/条件/引用/无结果/版本与泄露边界；所有实际用户输入走本地索引，不仅匹配预置问句。

## 13. 交付与回滚

设计阶段只核对五份规格、目标/资产/任务/旅程映射、金额/答案一致性、知识来源与适用边界、Markdown 链接和 Git 差异。没有应用代码改动，不运行应用测试或建立开发完成标签。

后续 P1 完成且通过验证可建 `baseline/teaching-t1-m1`；P1–P3/TJ01–TJ13 全部完成后才建 `baseline/teaching-t1.0`。这些开发标签当前不存在，不提前创建。设计标签只保存本次设计稿，旧标签保持不变。

沿用现有开发分支保存设计，不覆盖工作区、不推送、不部署、不安排代理分工。代码回看采用独立 worktree；浏览器数据按新旧库隔离规则处理，回滚代码不会替用户迁移或合并数据。
