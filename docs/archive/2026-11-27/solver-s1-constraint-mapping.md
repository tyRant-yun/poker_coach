## 3. 独立验证项与证据分层

- **S1 必需但待开发验证**：SDK client 通过实际 stdio 协议调用、资源读取、双入口接手、并发/幂等、关闭浏览器及运行时故障、大结果分页、统一暴露。这些不等待真实引擎。
- **R1–R3 独立真实计算验收**：固定模型与输入输出、独立基准及误差阈值、质量定义、耗时/峰值内存、实际采用与运行环境、锁定/存档/续算。源码研究或原生/适配器同源一致只能作为部分证据。
- **当前已做**：原源码阅读和本文档修订/检查；没有 S1 MCP server、客户端调用证据或真实引擎运行证据。不能把本聊天工具调用或同名 JS 函数测试计为项目 MCP 通过。
