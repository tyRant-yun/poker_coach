# AR1：手后自动参考分析

日期：2026-11-26。用户授权“设计任务包，然后执行”。冻结任务为 [AR1 任务包](riverline-auto-review-task-design-2026-11-26.md)。承接此前同一聊天未提交的练习首屏/下一手布局修正；未覆盖其工作。固定 Bot 发行和 Solver 算法未修改，没有推送或部署。

## 已实现的闭环

完成整手自动登记报告 → 后台提取每个 Hero 决策前缀 → 四街导航/原牌桌 → 当时底池/跟注价格 → 合格转牌/河牌真实计算 → 参考频率/行动 EV/假设内 EV 差 → 查看双方参考范围矩阵 → 一键打开同案例、同解、同节点与 Hero 的图形研究 → 返回原手。旧历史手牌打开复盘时可补建派生报告。

自动报告数值来自真实原生 Solver，不是合成示例。输入范围则是公开定义的参考假设，未按原行动推断真实范围，也没有验证其属于翻前 GTO 策略。双方保留多手牌，不把已知对手底牌作为范围。数字和解释不构成原整手的均衡评分或针对 Bot 的最佳回应。

## 实际分析覆盖

| 街道/情况 | 本轮行为 |
|---|---|
| 翻前、翻牌 | 原决策回放、行动前事实、跟注价格/直接赔率与下注比例；不生成均衡行动EV或对错判断 |
| 转牌 | 两人街起点，有限参考范围、每方单尺寸、无再加注；后续河牌采用过牌摊牌简化。不能称完整转牌策略 |
| 河牌 | 两人街起点，有限离散树；原前缀/原下注尺寸准确入树后才评价，不把近似尺寸当原行动 |
| 六人剩两人 | 仅该街起点已是两人的局部参考，明确忽略弃牌相关性；不能称六人均衡 |
| 多人/街内从多人变两人/无法表达的行动/不可达组合 | 保留原手与原因，缺失指标不填零，不拼接其他模型的损失 |
| 预算结束未达目标 | 保留真实数字与质量状态，不显示确定的假设内EV差 |

行动 EV 使用同一解/节点/玩家/具体组合、当前节点收益原点。假设内EV差等于该节点最高行动EV减原行动EV，不累加成整手损失；低频行动不自动判错。直接底池赔率未计后续下注、权益实现、抽水或多人边池，不能独立证明跟注盈利。

## 数据与权限

报告为可再生 SQLite 缓存；输入/规格/原生解仍由唯一研究制品仓拥有，不向手牌写入整棵求解树。练习备份原格式兼容，导入后补建报告；真实解仍需研究备份。当前工作区丢失原解时，报告撤去旧数值并提示重算。

正常关闭会取消在途报告；异常重启将运行中报告标为中断，可按相同参考重试；等待报告在服务使用练习模块后继续调度。后台未展示的求解不登记答案暴露；用户读取已有数值的报告后登记同一权威参考暴露。新手或独立题进行时四个工具均拒绝报告读取/重试/取消/打开，最终返回前再次检查。

## 性能与验证

固定四街 HU 过牌样本的隔离端到端报告约 988ms；转牌/河牌节点分别约194/232ms，包含 Node 规格/制品提交与原生查询；两个节点达到其规格质量目标。该样本的报告 EV/频率逐项等于固定原生查询。事实街道无伪造EV。机器可读记录见 [AR1 对接与耗时样本](../../solver/validation/ar1-review-evidence-2026-11-26.json)。不是全范围、翻牌、大树或默认大 journal 性能承诺。

已观察通过：类型检查/生产构建、105 状态测试、14 规则/整手/Bot/报告测试、16 TS/CLI Solver 测试、12 Rust 测试、6 真实 MCP 测试（82工具）。6个转牌与10个河牌独立数值基准及其4/7个oracle自测复跑通过；原部分河牌问题达到迭代上限而未达更严引擎目标的事实保持。

浏览器：最终完整 **58/58 通过**（35旧版、13研究、10整手/布局/AR1，4.6分钟）。包含新增 AR1 四街→真实行动EV→同解图形研究→手机→参考重算。截图实际查看于 .artifacts/auto-review/screenshots/。

过程失败保留：首次 Solver 合同检查发现新增 maxSeconds 尚未生成 JSON schema，更新后16/16通过。首轮14条主流程11/14：研究备份增大触发旧单包1MiB限制，改用既有分块协议；NJ09误取列表首个转牌规格，改按URL固定作业取解；笔记折叠区异步开关与旅程加载时序冲突，改为独立用户开关并等待来源加载。第二轮13/14：分块导入与页面浏览保存发生正常版本冲突，客户端读取最新版本后重发被拒绝的块；对应恢复旅程单独通过。没有扩大传输上限、降低数值阈值或删除恢复断言。

## 使用与剩余范围

后端发生修改，原 npm start 服务需正常停止后重新 npm start，再强制刷新浏览器。完成一手进入“复盘这手牌”，在牌桌下方“手后分析”选择街道和决定；范围/计算条件中可切换参考并重算。新建手牌期间参考仍被隔离。
