# Demo 理想流程与异常评审脚本

状态：本次已通过状态测试与 Chromium 旅程组合验证 J01–J09，57 项状态测试、20 条浏览器旅程及类型检查/构建通过。实际映射、截图与局限见 [第一版交付](demo-v1-delivery.md)。以下为可复演脚本，按钮名称以实际 UI 为准；不将自动化通过表述为全部原生窗口的人工验收。

## 1. 准备

启动本地应用，设置 outcome=ideal、固定 fixtureVersion、正常或快速速度，使用新的演示 session。确认无真实 API Key 或外部业务服务。

页面持续存在轻量演示标识。打开版本与来源详情，能看到当前案例、节点、修订和 synthetic 标签。

## 2. 主演示路线（J01/J03/J05，约 10–15 分钟的设计目标）

| 步骤 | 操作 | 观察 |
|---|---|---|
| 1 | 工作台→局面库→S01 | 位置、牌面、规则、范围和假设完整 |
| 2 | 无需完整作答，加载参考或运行模拟；查看任务规格与状态 | 参考绑定当前节点输入，未覆盖不套用数值 |
| 3 | 选择 Hero、牌类与具体花色组合；切换结果视图 | 牌面图案、全范围矩阵、组合概率联动；输入权重与行动频率不混淆 |
| 4 | 进入后续行动/发牌节点，返回上游；打开假设对照 | 玩家、牌面、范围、策略与输入引用同步，未覆盖/需复核可见 |
| 5 | 按需进入范围编辑，批量/锁定/撤销，补完后提交 | 创建固定 PolicyRevision，编辑不改写参考或旧版 |
| 6 | 打开评价与组合差异 | 结构、频率、示例收益分别显示；未匹配项不假装可用 |
| 7 | 定位诊断→查询理论 | 条目有条件、来源和相关节点 |
| 8 | 运行“分析并建立改进分支” | 计划、工具轨迹、预算、实际分支和 patch |
| 9 | 查看改进前后与报告 | 可以定位到两个固定策略版本 |
| 10 | 将问题转为训练→独立作答 | 参考与未来信息隐藏 |
| 11 | 提交→反馈→迁移题 | 首次证据未被修订覆盖；新局面有自己的输入 |
| 12 | 学习记录→报告→导出 | 辅助状态、示例标签和版本都保留 |

## 3. 连续策略、实验与知识（J02/J04/J07）

1. S02 选择对手回应和至少三条后续分支，观察范围与覆盖状态。
2. 修改上游策略，看到下游复核提示；旧版本仍能打开。
3. S06 设置锁定对象/节点及补全方式，建立实验分支。
4. 比较基准与假设结果，示例数字不被写成真实结论。
5. 从理论条目进入关联实验，再保存有条件的研究笔记。

## 4. 复盘与预览（J06/J09）

1. 导入内置手牌，打开解析和待确认字段，再查看时间线。
2. 选行动前节点，确认未来牌、后续行动和对手私牌不在当前投影中。
3. 提取研究案例，不改写原始手牌；建立练习。
4. 导入未知文本，只保留待整理草稿，不虚构已解析动作。
5. 打开 S08/S09/S10，分别调整配置、查看报告和方法边界；预览不要求真实计算。

## 5. 异常与版本隔离（J08）

| 场景 | 操作 | 必须结果 |
|---|---|---|
| 取消 | running 时取消并等待原完成时刻 | 保持 cancelled，无迟到报告 |
| 失败后重试 | 开启 fail-once，提交、重试 | 首次失败原因明确，重试有新执行记录 |
| 资源限制 | 开启 resource-limit | 预检阻止；未静默删尺寸或降精度 |
| 输入改动 | 作业中修改范围或牌面 | 结果只属于原版本，当前页不被覆盖 |
| Agent 冲突 | 任务读草稿后手工编辑 | 显示版本冲突，可转新分支，无覆盖 |
| 没有 fixture | 任意修改成未预置条件 | 草稿保留，定量示例结果不套用 |
| 精度不足 | 开启 incomplete-quality | 完成与质量分开，报告保留限制 |
| 刷新中断 | 运行时刷新 | 显示 interrupted，可重播，无伪后台执行 |

## 6. 本地恢复与导出（J09）

1. 保存两个案例与多个策略版本，刷新后恢复。
2. 旧版本“恢复”为新草稿，历史制品不变。
3. 导出 JSON/Markdown，检查范围、版本、synthetic、提示状态未丢失。
4. 重置只影响本应用命名空间；重新导入恢复关联。
5. 损坏 JSON、未知 schema、缺少 fixture 引用应得到明确反馈，不丢原内容。
6. 无痕或无存储权限时说明未持久化，内存编辑与导出仍可使用。

## 7. 视觉与交互检查

- 1440px 与 1280px：主工作台无内容遮挡、主操作始终可达。
- 矩阵分色、数值、图例与动作一致；未知和零视觉可区分。
- 具体组合显示两张可辨认花色的紧凑牌面；列表、详情和版本比较一致，内部组合 ID 不因展示改变；选中边框、锁定图标与频率比例条可区分。
- 1024px：侧栏折叠，核心编辑可访问。
- 键盘：选择格子、编辑频率、关闭弹窗和恢复焦点可完成。
- 运行轨迹与报告可点击返回对象，不只显示文本。
- 对话、任务日志、来源说明不压过当前策略编辑。
- 主按钮不能是无反馈空实现；预览操作应有完整的本地模拟结果。
