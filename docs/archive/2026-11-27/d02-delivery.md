## 推荐演示

1. `npm run dev`，打开 <http://127.0.0.1:5173/library>，点击“打开双版本示例”。
2. 在“版本记录”查看两版整体分布，点差异矩阵中的 AA，再检查各组合的权重和 X/B33/B75 概率；打开两版反馈确认报告来源。
3. 恢复 V1，进入 V3 草稿；选择 AA 的一个具体组合并锁定，再选择整个 AA 批量分配混频，检查锁定组合保持不变；撤销、重做。
4. 拖选 KK/QQ，一次批量应用；通过类别和花色筛选选择更大范围。切换“具体组合”和“焦点模式”。
5. 切到“输入权重”，对 BTN 的 AA 设置 0：活跃组合由 569 减为 566。提交并模拟，当前自定义范围显示未覆盖；旧版参考和报告仍可打开。
6. 在版本记录中命名新研究分支；刷新或导出备份，确认源案例、版本、报告、锁定和编辑历史保留。
