## 2. 模型、合同与结果语义

五张公共牌，双方输入范围；联合私牌权重是双方输入权重乘积、在不冲突的组合对上归一化。OOP check/一个下注，check 后 IP 只能 check；面对下注 IP fold/call。无 raise、无抽水、无 bunching、无翻后后续价值近似。多下注尺寸、其他街道和多人请求明确不支持。

输入允许 1,326 格范围，但独立数值样本每方只有 2–3 个正权重组合。不能把小树性能或验证范围推广到任意密集范围、大树。正权重公共牌冲突、重复 combo、未知字段及会引起金额取整的尺度均拒绝。自动添加全下、强制全下阈值和尺寸合并全部关闭。

金额：整数 centibb，即 1/100 bb；起始底池和有效后手与历史投入分开。显式生成的根下注按实际动作核对，不静默删尺寸。

组合：引擎卡牌编码、私牌顺序与 action-major 索引由上游 API 显式取得；独立 oracle 通过实际卡牌对核对，不猜测索引。范围浮点权重和策略浮点频率保留，不转回编辑器整数精度。

EV：`compute_current_ev` 的根收益减去起始底池一半，构成无抽水零和口径；`expected_values` / action EV 使用当前节点之后的收益口径，已有投入视为沉没。换为根净收益时减去该玩家的路径投入。根聚合、逐动作以及有正到达的终局数值均独立核验。缺到达的数值不作为误差或质量依据。

质量：独立枚举双方纯策略最佳响应，NashConv 为单边改进量之和；该模型下引擎 exploitability 为 NashConv/2。锁定后的引擎指标单独标记为未独立验证，不沿用无约束质量结论。

## 3. 独立验证与资源

阈值预先登记在 `benchmarks/solver/river-cases.json`：频率和误差≤1e-5；终局及 action EV 误差≤1e-5 bb；NashConv 与 LP 价值差分别≤根底池的 0.001。最多 100,000 次迭代、600 秒、2 GiB。内核分配前检查估算值，外部基准脚本监测进程时间/RSS；尚无生产级硬内存隔离。

Python oracle 自己枚举七张牌的五张子集与终局收益，构造有限博弈收益矩阵，用独立 HiGHS LP 求价值，另算纯策略最佳响应。它不调用待测引擎评估器、求解器或 BR。还校验输出输入与预登记输入一致，避免引擎改动问题后依然通过。

在既有 R1 门槛通过后，补充了根节点 equity 的独立一致性检查（绝对误差≤1e-6），四例最大误差约 3.67e-8；它是额外检查，不追写为最初预登记门槛。

| 案例 | 独立 OOP 价值 bb | NashConv bb | 终局最大误差 bb | 动作最大误差 bb | 迭代 / 引擎停止目标 |
|---|---:|---:|---:|---:|---|
| 极化、满池下注 | 7.5 | 0.000242825 | 3.71e-7 | 4.66e-7 | 100,000 / 未达到 |
| 不对称、半池下注 | 8.717948718 | 0.0000183333 | 1.07e-6 | 8.03e-7 | 15,950 / 达到 |
| 私牌阻断、75% 下注 | 9.528571429 | 0.0000072265 | 6.10e-7 | 7.40e-7 | 2,070 / 达到 |
| 公共牌同花顺平分 | 5 | 0 | 0 | 约 8.88e-16 | 10 / 达到 |

四例均达到独立验收门槛。第一例的更严格引擎停止目标是 0.001 centibb，最终为 0.012191772 centibb，迭代预算用尽；该事实与独立门槛通过并列保留，不能改成“所有目标达标”。

精确执行耗时、RSS、输入/输出/二进制哈希见 [机器可读证据](../../../../solver/validation/r1-river-evidence.json)。小树内核耗时仅数十毫秒，进程开销另计；短进程未被采样时 RSS 为 null。该证据是本机单轮小树基线，不是一般性能承诺。

## 5. 发现并处理的问题

1. Rust 1.99 构建上游原生示例时触发 `dangerous_implicit_autorefs`。固定 Rust 1.85.1 后原生编译通过；没有关闭该检查或改写算法来掩盖失败。最初使用 1.99 编译的实验输出已被最终固定工具链的报告替换；验收证据只使用最终版本。
2. 上游 bincode 宽松预发布版本会解析到 2.0.1，与旧 Decode API 不兼容。本外壳精确锁定 bincode 与 derive 为 rc.3，并提交 lock。
3. 上游不启用存档 feature 时，默认 `cargo test` 仍试编 file_io 示例而报缺接口。改用明确的 `--lib --tests` 测试目标；basic 原生示例单独编译。外壳的存档 feature 则真实启用并通过读回测试。
4. 纯 root-node EV 对照不足以发现投入偏移。本批增加路径 ledger、逐动作与终局独立 EV 检查；零到达节点不补零或纳入正确性结论。
