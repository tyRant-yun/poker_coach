## 4. 黄金旅程

每条记录输入/seed、工作区、版本/哈希、模型、环境、实际命令、结果和失败日志。UI/应用链路不成功 mock。长计算可用已验证持久解做查询旅程，但不能代替新计算/取消/失败测试。

| 编号 | 旅程 | 必查 |
|---|---|---|
| UG01 | 真解→独立决策→提交→反馈→研究→新题 | 所有入口提交前无答案，原答固定，研究暴露影响新题身份 |
| UG02 | 连续两手→标记→行动前复盘→研究 | 随机性、无重牌、合法动作、摊牌/补码、事实/假设、未来隔离 |
| UG03 | 自定义合法额→未评分→改树→真实计算 | 原额、to/increment、无近似吸附、两版保存 |
| UG04 | Hero→牌类/组合→双方范围→动作/发牌 | 联动、死牌/不可达、分母、分页；无六节点或整树快照假设 |
| UG05 | 基准→约束→再求解→条件结论 | 锁定对象/自由度、受约束质量与原博弈指标分开 |
| UG06 | 训练中看研究/MCP→返回→刷新 | 先记暴露、身份准确、跨入口无绕过、原答不变 |
| UG07 | 计算时关网页→重开→查询 | Node 继续，结果绑原输入，旧结果不替换新草稿 |
| UG08 | 杀 helper/worker→重试/重复命令→取消竞态→重启 | 不重复行动/发布半解；中断、取消、太晚分开 |
| UG09 | 导出→新工作区导入→恢复解/学习 | 引用闭包/摘要/reader/unknown exposure，不倒写原件 |
| UG10 | 多分辨率/键盘/缩放 | 主任务、稳定动作区、对比度/焦点、无关键遮挡 |
| UG11 | 预解命中/失配/输入变动/逆花色 | 精确规格/质量，无近邻数值冒充 |
| UG12 | 翻前→逐街行动→合法终局→手后反馈→节点研究→返回整手 | 包含早期弃牌/全下、暂停重连；反馈不提前泄漏；评价覆盖缺失不当零，不混加不同局部 EV |
| UG13 | 原手行动线→双方范围/组合→改尺寸/混频→实验/后续牌→保存对照→整手变体 | 每个已开放研究能力有真实制品，局部解假设与跨街继承可追溯；变体已见/未见判定准确 |

## 5. 工程方法

先完成一个可见闭环再抽共同接口，共享合同变更同步验证消费者。金额、规则、隐私、持久化、取消竞态、Solver 数值为高风险；样式/文案只跑对应检查。

锁定依赖/引擎/schema/规则/评分版本，跨语言黄金样例。规则重放不变量、同源读取一致、独立终局/LP/BR 分别记录，不能互相代替。实际触发 worker 退出、坏制品和重启，不能只测成功 fixture。

实现后按影响运行 typecheck/build、状态/合同、规则/Rust、真实 MCP、对应浏览器旅程；阶段出口一次完整回归。提交前 diff check，只暂存本批文件并检查 staged diff，不夹带在途应用修改、不移动标签、不自动推送/部署。

性能/稳定性/覆盖用实测分位数与样本报告。未测任意全范围不称任意树可用；未做用户研究不称学习效果已证实。
