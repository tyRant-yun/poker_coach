# AR1 手后自动复盘任务包

日期：2026-11-26。用户授权“设计任务包，然后执行”。按 AR01→AR05 连续实施验收，不安排代理，不推送/部署。保留本轮之前未提交的练习布局修正。

## 本轮产品出口

整手结束自动登记报告→四街决策导航/行动前牌桌→事实与跟注价格→符合模型的转牌/河牌后台真实分析→图形行动EV/频率与假设内EV差→一键打开同一案例/解深入研究。无需用户先填写范围。翻前/翻牌/多人提供事实与明确的未评价原因，不伪造均衡答案。

自动范围先采用公开定义、版本固定的有限参考假设，按整牌类展开，不从对手底牌或未来公共牌生成，不宣称已从行动历史推断真实范围或已验证翻前策略。Hero 牌类加入己方参考范围；双方范围都保留其他手牌。用户可选择紧/标准/宽参考，图形查看范围与实际组合数量。所有数值都是该假设和受限树内的真实求解结果，不是整手评分或针对 Bot 的最佳回应。

## 资源与语义

- 每次后台只提交一个真实作业；共享既有单计算槽/两个查询槽，不新增求解器实例。等待手工作业队列空闲再提交。自动计算采用最多 8 秒/5000 次迭代/原有 256MiB 预检估算；不是硬内存隔离。首版每份报告最多自动算 8 个合格节点，其余可选节点按需重新分析。
- 以该街开始为根，按真实前缀读取目标 Hero 决策。河牌显式树纳入实际路径与原下注尺寸；转牌沿用每街每方单尺寸无再加注模型，无法精确表达则不打分。
- 行动EV使用同一解、同一节点、同一Hero组合和当前节点收益原点。原行动匹配精确动作/金额。仅目标质量达标且组合可达时显示假设内EV差；预算耗尽保留数值与质量说明，不给确定判断。
- 后台可以处理已完成手牌；新手进行时 UI/HTTP/MCP 不得读取报告或相关研究资源。报告输入禁止完整deck/未来牌/他人私牌。
- 报告是可再生的 SQLite 派生缓存，不把原生解/整树写入手牌。既有练习备份格式保持兼容，导入后按原手重新生成报告；研究备份仍独立。关闭时取消后台任务；重启将运行中标为中断并允许按固定假设重试。
- 本轮不包括新翻前均衡库、翻牌原生接入、多尺寸转牌/多人均衡、Bot策略画像、LLM解释、整手总损失或真解定向复练。这些仍需独立验证。

## 验证与交付

先冻结该合同，再实现。数据测试覆盖前缀身份、四街、参考范围无隐藏信息、动作尺寸精确、EV差计算、质量门、取消/重启/信息门。数值对接逐项比较报告与固定原生查询；不以桥接自洽替代已有独立求解基准。新 MCP 工具走同一个服务；浏览器从真实整手进入报告与同解研究，检查手机及参考限制。交付文档分别记录实际自动覆盖和仍未覆盖的街道。
