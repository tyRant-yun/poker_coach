# 当前状态

更新：2026-11-27。功能基线来自AF工程交付与三仓库整理；本轮是文档整合，没有新增扑克能力。项目处于本地开发阶段，尚非通用全街Solver或已验证强度的Bot产品。

## 已有能力

| 模块 | 当前行为与边界 |
| --- | --- |
| 规则与练习 | PokerKit0.7.8；原生HU/6-max整手，固定/随机/轮转位置、稳定Hero身份、动作播放、标记与保存；100BB每手重置 |
| 手后报告 | 结束后直接显示报告、下一手置顶；四街原决定/疑问导航、覆盖/质量、已覆盖节点的行动EV、频率图和规则建议 |
| 自动求解 | 合格原生HU转牌/河牌后台真实计算及缓存；转牌后续包含双方有限河牌下注。范围仍是未按完整历史更新的有限假设 |
| 河牌研究 | 给定范围的一般HU离散下注/加注树；产品每方最多200个正权重组合，实际仍需预检 |
| 转牌研究 | 每方最多128组合；转牌到合法河牌，逐街逐方单一固定下注尺寸、无再加注 |
| 翻牌研究 | 每方最多16组合；翻牌→转牌→河牌，同类单尺寸限制；真实预设、作业/分页/图表/恢复已接入 |
| 研究往返 | 固定原手前缀、Hero、行动路径和同解引用；刷新恢复浏览状态，返回原手保留决定 |
| Bot | 默认基础启发式；可选HU v2.2.2 final-r9实验候选，受观察/合法性/进程时限约束；整体强度未证明 |
| 策略包 | 规范JSON候选导入、精确路径/组合查询、人工接纳记录及独立SQLite持久化；合成包不能作为真实评分来源 |
| 教学与旧示例 | 历史课程/模拟研究保留，数值性质明确标识；未接入真实LLM |

HU能力指原生两人规则与声明模型；六人剩两人不自动获得等价策略覆盖。计算使用固定上游和单线程。离树、组合过多、不可达或质量不足均保持明确状态。
