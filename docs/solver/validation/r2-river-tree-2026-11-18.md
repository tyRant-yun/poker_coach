# R2 一般河牌树：独立验证与原生查询基础

日期：2026-11-18。承接受限河牌产品提交 `780ff56`。本批完成扩大河牌模型前的引擎合同、独立数值验证与原生按节点读取；**没有将一般树开放到 UI/MCP，也没有进入转牌计算**。上一批产品能力仍按 [受限河牌交付](r2-river-delivery-2026-11-18.md) 声明。

## 本批实际实现

继续依赖完整 postflop-solver 固定提交 `9d1509fe5077d019825f833eed04b16d342dfda1`，不修改 CFR、评估器或 BR。使用其 [固定版本 ActionTree 接口](https://github.com/b-inary/postflop-solver/blob/9d1509fe5077d019825f833eed04b16d342dfda1/src/action_tree.rs) 添加显式行动路径；保留所有必须的 check/fold/call，新增下注、加注与全下由引擎检查合法性。

新增内部 `schemaVersion: 2` 输入和 `validate-river-tree` 命令，与原 `schemaVersion: 1`/worker 分开。`treeLines` 是按父路径在前排列的新增进攻行动路径，金额为 **本条河牌街累计投入至多少 centibb**，不是新增投入；100 centibb = 1 bb。没有百分比取整、相近尺寸合并或自动加全下。`bet(stack)`/`raise(stack)` 明确拒绝，调用者必须声明 `all-in`；重复路径、缺父路径、非法最小加注、全下后再加注等返回失败。

例如两个 OOP 尺寸、check 后 IP 下注，以及某一路径上的加注均可分别声明。范围仍是给定的组合输入权重；这不会计算翻前范围，也不宣称连续动作空间中的完整 GTO。内部合同不是整个产品的数据模型，未来产品局面/行动树仍由局面模块拥有。

预算：最多 128 条新增路径、每条最多 16 个行动，最多 128 个锁定节点；最多 100,000 次迭代、120 秒与 256 MiB 引擎估算。范围按原生上限 1,326 个组合检查，但**独立质量样本仅为每方 2–3 个组合**；没有因此验证全范围性能或任意大树。当前研究命令对小树收集完整报告用于核验，禁止将该方法用作业务工作区保存或 Agent 查询。

## 独立数值基准

`benchmarks/solver/river-tree-cases.json` 在首次运行前冻结六个问题、预算与门槛。Python 验证器独立构建预期树、账本和终局收益，复用先前独立的七张牌枚举比较器，不读取引擎评估器/BR。它构造微型完整纯策略收益矩阵，使用 SciPy/HiGHS 的约束零和 LP 计算价值及双方最佳响应。

内部节点锁定通过自身行动序列的 realization 约束表达，不能用无条件边际频率替代。验证原生锁定列本身，也验证行为策略转纯策略分布满足约束。原博弈与受约束博弈的 NashConv 分别计算。

| 样本 | 核验重点 | 结果 |
|---|---|---|
| `river-two-sizes-ip-bet` | OOP 两尺寸、IP check 后下注；12 节点 | 独立 LP/BR、EV/权益/范围通过 |
| `river-raise-reraise` | IP 加注、OOP 再全下、深层跟注账本 | 通过 |
| `river-ip-bet-blockers` | 非对称权重、私牌阻挡、双方下注 | 通过 |
| `river-short-allin-tie` | 小于完整最小加注幅度的全下、公共牌平局 | 通过 |
| `river-root-mixed-lock` | 单组合根节点 75%/25% 锁定 | 受约束质量通过；原博弈 NashConv 约 1.25 bb |
| `river-interior-mixed-lock` | 中间节点 10%/20%/70% 锁定 | 列约束、自身条件序列及价值通过 |

冻结门槛：可达策略列和误差 ≤1e-5；节点 EV/action EV 误差 ≤1e-5 bb；权益与条件组合比例误差 ≤1e-6；上游质量指标换算误差 ≤1e-5 bb；受约束 NashConv 与 LP 价值差均 ≤根底池的 1e-3。六项均达到本次引擎停止目标；旧 R1 的预算耗尽样本仍保留原状态。

原生金额/EV 单位为 centibb；节点 EV 将路径已投入视为沉没，含终局未跟注返还，换回根收益需减该玩家已投入。`compute_current_ev` 则使用减根底池一半的中心化原点。本次在全部有定义的节点/组合核验该换算，包括弃牌、加注、再加注终局；不可达值不拿零作数值预期。

原生锁定结果的 `qualityScope` 为 `fixed-constraints-half-constrained-nashconv`，表示固定约束内的半 NashConv。它不能充当原博弈均衡证明、固定双方策略评价或统一的教学分数；真实策略实验产品仍待 R2-F。

## 原生按需查询

新增内部 `query-river-tree NATIVE QUERY.json PAGE.json`。请求带原生文件 SHA-256、节点索引路径、玩家、offset/limit 和解码内存上限；每页最多 100 组合。校验原生文件与模型 memo 后仅访问指定节点，不遍历整树。一次查询重新加载原生解，目前没有常驻游标或缓存；这是正确性基础，尚未做大解吞吐优化。

同一打开的文件句柄用于流式校验与反序列化；拒绝文件符号链接、非普通文件、错误 checksum、错误 memo、坏路径、越界分页、过大查询及解码限额不足。单页输出最多 1 MiB；原生文件和解码上限均最多 256 MiB。该读取限制仍不等于进程硬 RSS 隔离。

返回的 `engineIndex` 仅为内部组合顺序，后续产品适配仍须按实际组合映射，不得成为公共组合 ID。自身路径权重与兼容质量均为原生未归一化权重，不是从根的真实到达概率。不可达组合 EV/权益返回 null；非行动玩家和不可达组合不提供策略/action EV，终局不伪造行动策略。

实际从二进制重载完成 48 次分页，覆盖 12 节点 × 两名玩家 × 两个单组合页；每页与研究报告逐字段一致，最大 482 bytes，26 个不可达组合页保持空指标。该一致性只验证读取/映射，独立质量证据来自上节 LP/枚举，二者不互相替代。
