## 2. 开发原则

先交付第一个真实可操作闭环，再扩大覆盖。脚手架与核心旅程同一批推进，不长时间停留在目录或导航壳。

所有任务均为同一 Demo 的后续开发任务；当前没有创建远程 issue、外部项目或额外聊天。无需提前拆微服务或引入真实业务依赖。
