# T1 教学内容与翻前路径规格 v0.1

日期：2026-11-12。状态：设计合同与题目脚本草案，未建立应用 fixture，未发布课程。参数和频率均是自写的概念演示设定，不是 Solver 解或扑克行动建议。

入口：[产品设计](teaching-v2-product-design.md)。对象/版本/权限见 [领域合同](teaching-v2-contracts.md)。开发时必须将下列清单落实为可校验资产，不能仅复制本文就声称课程已完成。

## 1. 资产身份和发布

两个包初版固定 `LP-A@1`、`LP-B@1`，内容身份 `concept-demo`。旧 S01–S10 标为 `workflow-synthetic`，不升级为新课的证据。未来真实解的身份预留，不接真实引擎或受限数据。

发布状态采用 `draft / demo-ready / disabled`；另存 `structuralChecks`、`authoredConceptReview`、`independentReview`。T1 允许“结构校验通过、作者自检、未独立教学审核”的演示包上线，并持续显示该身份。没有独立审核时不得自动写为“专家审核通过”。

每包必须有 manifest、固定输入/树/结果示意、类别表、解释与限制、题目及答案键、评分政策、对照、反例、迁移/延迟题、连续片段。所有条目独立 ID 与内容哈希，引用不得只用数组序号。

## 3. LP-A 输入与金额约定

示例条件：六人桌现金局，无前注、不计抽水；每人开局 100 bb，SB=0.5 bb、BB=1 bb。UTG/HJ/CO 已弃牌，轮到 BTN；SB 的后续弃牌为明确预置对手行动，不提前伪装成已发生事实。只有 BTN/BB 的教学范围参与示意，不计算其他弃牌玩家的移除效应。

金额用 1 bb=100 个内部单位。每位玩家分开记录开局筹码、累计投入、当前街道投入、剩余筹码；底池是本手所有累计投入之和。`raiseTo` 表示本街累计投入到多少，不是额外再投入多少；UI 同时显示本次增量和加注至的金额。

“有效剩余筹码”在等待跟注时不能只显示一个未解释的数。新抽屉展示双方各自剩余与待跟注量；旧 Study 的 `stackMinor` 作为兼容摘要，使用双方剩余的较小值并注明口径。等额跟注完成后的值可直接作为后续翻后有效筹码。

不引入通用规则引擎；开发时用下列明确路径和金额表做有限一致性校验。示例之外输入保留但没有结果。

## 4. LP-A 有限树与账本

| 节点 | 前序及当前行动方 | 底池（bb） | BTN / BB 剩余（bb） | 树内可选动作 |
|---|---|---:|---|---|
| A-P0 | 前位弃牌，BTN 决策 | 1.5 | 100 / 99 | Fold、RaiseTo 2.5 |
| A-P1 | BTN 2.5，SB 弃牌，BB 决策 | 4.0 | 97.5 / 99 | Fold、Call 1.5、RaiseTo 10 |
| A-P2 | BB 加至 10，BTN 决策 | 13.0 | 97.5 / 90 | Fold、Call 7.5、RaiseTo 22 |
| A-P3 | BTN 加至 22，BB 决策 | 32.5 | 78 / 90 | Fold、Call 12 |
| A-F1 | BB 跟至 2.5，发 Qs9h5d，BB 决策 | 5.5 | 97.5 / 97.5 | Check；预置此行动后进入 A-H1 |
| A-F2 | BTN 跟至 10，同一示例翻牌，BB 决策 | 20.5 | 90 / 90 | Check；进入 A-H2 |
| A-F3 | BB 跟至 22，同一示例翻牌，BB 决策 | 44.5 | 78 / 78 | Check；进入 A-H3 |
| A-H1/2/3 | 相应 BB Check 后，BTN 决策 | 对应 5.5/20.5/44.5 | 同前一节点 | Check、BetHalfPot |

Fold 终局区分未结算投入池、未跟注退还与结算底池：

| 终局 | 未结算投入（bb） | 未跟注退还（bb） | 结算底池与归属 |
|---|---:|---|---|
| BTN Fold，随后预置 SB Fold | 1.5 | BB 0.5 | 1.0，归 BB |
| BB 在 A-P1 Fold | 4.0 | BTN 1.5 | 2.5，归 BTN |
| BTN 在 A-P2 Fold | 13.0 | BB 7.5 | 5.5，归 BB |
| BB 在 A-P3 Fold | 32.5 | BTN 12.0 | 20.5，归 BTN |

退还与底池奖励分别记录，不能把包含自己投入/退还的毛额当净利润；T1 不为这些终局输出策略盈利评分。以上是有限预置账本，不是通用结算规则引擎。

三个 Call 路径均能进入对应翻后节点，不能只换标题复用 5.5 bb 的结果。A-H 系列提交后结束为“教学片段已完成”，不是虚构摊牌。未建模的 Limp、其他尺寸、5-bet 和 BB 翻牌下注有明确树边界，不标为真实扑克中不合法。

固定发牌由用户选择示例，不声称来自随机发牌分布。进入翻后时逐项排除公共死牌，记录排除前/后质量，不自动把剩余权重归一化回 10000。

## 5. LP-A 范围与示意分配

BTN 起始示例集合为 AhJh、AdJd、AcJc、KsJs、KcJc、7h7d，各权重 10000。BB 为 AsKd、AhKc、KdQc、QhJd、9s9c、6h6d，各权重 10000。它们是缩小后的教学输入，**不是任何位置的真实完整范围**。两个玩家的候选范围可有共同牌，实际对局的私牌相容性未计算，不能把单方汇总称为真实到达概率。

作者示意表（每行合计 10000）：

| 节点 | 组合或范围 | 示意行动基点 |
|---|---|---|
| A-P0 | AhJh / AdJd / AcJc | Fold 2500、RaiseTo2.5 7500 |
| A-P0 | KsJs / KcJc | Fold 5000、RaiseTo2.5 5000 |
| A-P0 | 7h7d | Fold 0、RaiseTo2.5 10000 |
| A-P1 | BB 上述 6 组合 | Fold 3000、Call 5000、RaiseTo10 2000 |
| A-P2 | BTN 上述 6 组合 | Fold 4000、Call 4000、RaiseTo22 2000 |
| A-P3 | BB 上述 6 组合 | Fold 6000、Call 4000 |
| A-H1/2/3 | 当前有效 BTN 集合 | Check 5000、BetHalfPot 5000 |

这些值仅用于演示权重变化与策略作品，不附会扑克原因。开发时展开为显式、带来源的组合分配，不用索引公式生成后声称有理论依据。

单玩家示意：AhJh 经 BTN Open 后权重为 7500；若再由 BTN 选择跟 3-bet，其保留权重为 7500×0.4=3000；若改为 4-bet 路径，则为 7500×0.2=1500。这是不同分支，不将两者当同一份继续范围。对手行动只记录其自身范围变化，不通过相乘对手频率来伪造 Hero 条件分布。

若中间结果不能精确表达为基点，派生权重保存分子/分母或更高精度，显示时才取整；不可在每条边反复四舍五入累积。原输入权重和动作概率仍使用既有整数基点。

| 资产 | 题干/改动 | 允许自动反馈 |
|---|---|---|
| A-I01 | 当前 A-P0 轮到谁，SB 弃牌是否已发生？ | BTN；尚未发生。不能在行动前投影中提前列为历史 |
| A-Q01 | AhJh Open 后，再跟 3-bet 的示意保留权重？ | 3000；写明单玩家简化，不能称真实条件概率 |
| A-Q02 | BTN2.5 / BB Call 后底池和双方剩余？ | 5.5 bb、各 97.5 bb；查看投入账本 |
| A-R01 | 给定 KsJs/KcJc/7h7d，用户分配三个 AJ 组合 | 三目标结构检查；题目显式选择“复现作者分布”时才显示样例差异 |
| A-C01 | 固定 A-P1，比较 BB Call 与 RaiseTo10 | 自变量为 BB 回应；列出产生的范围/金额/后续节点差异；不判哪个回应更赚钱 |
| A-C02 | BTN Open 从 2.5 改为 3，BB 均 Call，其余输入固定 | 独立变体账本：6.5 bb、各 97 bb；示意分配保持不变是作者假设，不推断真实策略不变 |
| A-X01 | 把 AhJh 与 7h7d 的 Open 分配互换，总 Open 量相同吗，范围作品相同吗？ | 相同总量、不同逐组合分配；起始权重相同保证该算例成立 |
| A-M01 | A-P1 题面当前轮到谁，待跟注增量是多少？ | BB、1.5 bb；独立迁移不展示 A-I01/A-Q02 答案 |
| A-M02 | BTN 跟至 10 后，翻牌前底池/双方剩余？ | 20.5 bb、各 90 bb |
| A-M03 | 新组合示例初始权重 5000，自身两步频率 6000/2500，保留权重？ | 750；与旧权重和数组 ID 无关 |
| A-D01 | BB 跟至 22 后底池/剩余，并指出为何不能沿用 SRP 的范围版本 | 44.5 bb、各 78 bb，前序路径不同；不提供原题照抄入口 |

迁移的“新”由输入/答案事实作用域与暴露记录共同判断，不因使用了 M/D ID 就成立。A-M01/A-M02 可能已在自由树中看过对应账本，此时如实标为已见过，不保证三题全部可作为新题。

连续片段 A-L01 默认教学路线为 A-P0 Open→A-P1 预置 BB Call→A-F1 Check→A-H1 用户行动；另有 3-bet/4-bet 路径可浏览和分支练习。开始前只说明“对手回应来自预置脚本”，测验不会提前给出具体回应。用户 Fold 则如实进入终局，不改回 Open；想走指定路线可新建一次 run 或片段，不覆盖之前选择。

## 7. LP-B 输入与分类事实

基础来自 LP-A SRP 快照：Qs9h5d，底池 5.5 bb、双方剩余 97.5 bb，BB 已 Check，BTN 决策。Hero 默认为 AhJh；6 组合沿用 AhJh、AdJd、AcJc、KsJs、KcJc、7h7d，具体权重引用 A-P0 Open 后的固定示意版本。

本包可共享 A-F1/A-H1 的事实证据，因此共享内容键和暴露身份；不是新建随机 ID 后重新归零。研究创建的是独立固定副本，不反向修改 LP-A run。

| 组合 | 在 Qs9h5d 上可核对的事实标签 |
|---|---|
| AhJh | 未成对高牌；后门红桃同花可能；当前不是同花听牌或成花 |
| AdJd | 未成对高牌；后门方块同花可能 |
| AcJc | 未成对高牌；无后门梅花同花可能（两张未来牌也不足五张梅花） |
| KsJs | 未成对高牌；后门黑桃同花可能 |
| KcJc | 未成对高牌；无后门梅花同花可能 |
| 7h7d | 口袋对子；不与上述高牌分组混为同一类 |

这份标签只覆盖声明的事实，不称完整牌型/听牌识别。没有声明的顺子听牌、阻断强度、最佳诈唬类别保持未知。每个组合独立核对花色和死牌，不能从“suited”直接推导任何牌面都有后门同花可能。

互斥大类为“未成对高牌/口袋对子”，后门花色是重叠标签；两种视图不得混加。类别统计使用固定输入权重，图例说明不是 joint matchup 频率。

## 8. LP-B 行动与连续片段

预定义动作 Check 与 Bet 2.75 bb（50% pot）。BB 回应 Fold 或 Call；Call 时底池 11 bb、双方剩余 94.75 bb。Fold 时退还 BTN 未跟注的 2.75 bb，结算底池为 5.5 bb。示例转牌为 2h 或 2c，BB Check 后轮到 BTN。若 BTN 翻牌 Check，则对应转牌底池仍为 5.5 bb、剩余 97.5 bb。

转牌 BTN 可 Check 或 BetHalfPot：分别按 5.5/11 bb 的当前底池计算 2.75/5.5 bb。选择后教学片段结束，不展示未发生的对手动作或河牌，不冒充完整牌局已结束。

LP-B 使用显式作者示意分配：AhJh/AdJd 为 Check4000/Bet6000，AcJc 为 Check7000/Bet3000，KsJs 为 Check5000/Bet5000，KcJc 为 Check7000/Bet3000，7h7d 为 Check8000/Bet2000。它仅展示“同类内部可以有不同分配”的作品形态，**上述花色事实不证明这些数值或差异是正确 GTO 行为**。两张转牌都有各自固定输入和示意结果记录，无配对数值则不显示。

连续片段 B-L01 开始时选择引导或测验。测验只记录动作/阶段，不显示参考、解释、对手私牌和未来牌；每到达一步才出现当前公开信息。片段结束再揭示对应结果。原题已见状态与本次是否用辅助分别保留。

## 9. LP-B 对照、反例和答案键

| 资产 | 题干/改动 | 允许自动反馈 |
|---|---|---|
| B-I01 | 给定 Qs9h5d，AhJh 是否已经有四张同花牌可组成同花听牌？ | 否；当前是后门可能，不能混为转牌四张同花的状态 |
| B-Q01 | AhJh / AcJc 是否在这张翻牌上具有相同后门同花条件？ | 否；依次核对公开牌和手中花色，不推断精确动作 EV |
| B-Q02 | “下注范围中某类别占比”与“该类别下注比例”的分母是否相同？ | 不同；列各自分母，无数据不显示零 |
| B-R01 | 给定 AcJc/KcJc/7h7d，只填写 AhJh/AdJd/KsJs | 只对三目标做结构检查与作者示意分布对照，其他分配不能计作用户填写 |
| B-C01 | 固定翻牌 Bet/Call 路径，只将转牌 2h 改成 2c | AhJh 在 2h 时有四张红桃可用、2c 时没有；不能据此单独断言必须下注 |
| B-C02 | 固定基础牌面，将 Hero AhJh 换为 AcJc | 只变 Hero 花色组合；比较事实及作者示意，精确频率原因未知 |
| B-X01 | 改为 Qc9s5d，AhJh 是否仍有后门红桃同花可能？ | 没有；推翻“同花手牌在任何翻牌都有后门同花”的结论 |
| B-M01 | KdJd 在 Qh9c5s 是否有后门方块同花可能？ | 没有；独立新组合/牌面 |
| B-M02 | AsJs 在 Qd9s5c2s 是成花、同花听牌还是仅后门？ | 同花听牌，未成花 |
| B-M03 | 两个策略总下注量相同，能据此确定具体组合构成和 EV 相同吗？ | 不能；分别缺组合分配与评价条件 |
| B-D01 | AcJc 在 Qd9h5c2c，指出同花状态，并说明是否足以决定最优动作 | 四张梅花的同花听牌；不足以决定最优动作 |

B-S01 总结必须允许“我观察到差异，但现有证据不足以解释精确频率”这一正确结论，不强迫用户写出不存在的 Solver 原因。

## 10. 解释条目与引用

最少建立 A-E01（范围权重）、A-E02（投入账本）、A-E03（同总量不同组成）、B-E01（花色事实）、B-E02（两个分母）、B-E03（事实不等于最优行动）六组解释，每组有主张、条件、支持事实、反例和局限。

理论背景可以引用已研究的官方概念文档，但来源字段区分 `backgroundConcept` 与 `numericEvidence`。官方链接只支持通用概念，不支持本地示意频率。自由文本不能仅凭提及“阻断/范围优势”就自动判为正确解释。

## 11. 迁移、复测与内容检查规则

迁移按目标错误候选优先、然后固定题目 ID 顺序选择；不随机生成未审核题。选题前核对内容键、输入/目标事实、暴露、已作答及缺失依赖。用户可在独立题主动请求提示，此次作答转辅助，不删除题目或改写先前状态。

每包总结完成后创建一项本地延迟题，默认到期为完成时刻 +24 小时；本轮不做 3/7 天递进题库。提前演示可新建 `demo-preview` 作答，不能完成真实到期任务或计为延迟保持证据。日期保存 UTC，按应用时区显示，无外部提醒。

发布/导入预检至少包括：ID 唯一、引用闭合、资产版本/哈希、牌面与组合相容、节点金额守恒、各概率合计、评分目标集合、互斥分类/重叠标记、解释身份、题干/答案分离、连续片段终止条件、迁移内容键与暴露规则。结构校验通过不自动提升教学可信等级。

所有答案键和数值均需开发时显式写入、逐项验证，本轮文档题目不等于已运行的课程或测试结果。
