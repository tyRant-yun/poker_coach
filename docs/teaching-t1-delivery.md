## 已实现的闭环

- `/learn`：LP-A 翻前路径与范围来源、LP-B 近邻花色与统计分母。每包 8 阶段，Hero 预测→证据→3 个目标组合→2 个受控对照→反例→多节点片段→条件总结→迁移/本地复测。
- 无需填完整范围。目标、给定与作者示意分开；批量填写、局部锁定、撤销重做、保存、刷新恢复、暂停、放弃及原预测回看真实工作。
- TP01/TP02 与原 S01–S10 并存。三条翻前底池、raise-to 增量、SB 死钱、未跟注退还及自身行动权重来源显式编写。Open 3 对照有独立完整来源；改变自定义输入后显示未覆盖。
- 对照生成两份实际研究案例与固定策略版本，保存预测、条件与观察；结论形成新作品，不冒充运行真实求解。研究页可继续调用原模拟作业与报告。新教学输入没有战略 EV 数值。
- 连续片段真的沿实际行动走多个节点，对手由固定脚本回应。Fold 如实结束；片段末最后一次下注仍更新账本，不编造摊牌。
- 概念、结构、固定权重 TV 分布距离、理由待审阅及战略 EV 不可用分别显示；固定 Attempt/题目哈希/评价/引用不被后来修订覆盖。
- 语义暴露跨标题/ID 复制关联；提示先登记后释放，失败不泄露正文。迁移题有独立投影与跨页面隔离；首次身份固定、辅助修订另存；有限题池耗尽明确告知。
- 24h 本地复测与提前演示分开。没有外部提醒、真实能力模型或“已掌握”预测。
- 理论库：24 主题/96 概念索引、36 条有定位的主张、12 公开来源、8 组误解/条件反例。正文有覆盖缺口，索引数量不等于正文数量；原 K01–K08 保留独立入口。
- 实际本地中英检索、主题和局面条件筛选、候选与排除原因；match/conflict/insufficient-context/general-background 分开。固定 RetrievalRecord、CitationBundle 保存主张和来源版本；精确示意频率无数值证据时不生成理论证明。
- 知识建设：问题→登记来源→自写/JSON 草稿→精确定位→用户显式核对条件/反例→不可变发布→本地索引。勘误、争议、撤回、来源离线与历史引用可操作；不把自报外部审核升级为可信正文。
- 教学 Agent 四意图实际调用同一应用命令：公开输入说明、针对提示、提交后检索引用、复习安排。逐步轨迹、额度、暂停、取消、重复调用保护和刷新中断真实工作，未接真实 LLM。
- 复盘严格核对输入。普通/缺字段牌谱不因牌面相同强配；另有明确的作者教材快照展示精确匹配→课程入口。原始牌谱与原旧版复盘流程保留。
- `/content`：内容哈希/概率/牌面/账本/范围来源/依赖预检、损坏草稿保留、新版本发布、停用；旧作品只读可回看。
- schema2 使用 `riverline-demo-t1`；只读迁移 `riverline-demo` 并保留原件。新库损坏不静默回退；导出/重置/导入恢复教学关系和知识版本，导入复制不制造新题身份。

## 实现边界与取舍

这是有限的概念教学 Demo。所有策略是显式作者示意，只有金额/牌面/概率/状态等声明事实进行结构或概念校验。没有接入真实 Solver、LLM、通用德州规则引擎、通用牌谱解析、账户、支付、云服务或真实牌桌。

教学范围仅六个显式组合；课堂要求三个目标组合，不能称覆盖完整 NLHE 组合空间的训练教材。分类只覆盖声明的花色/对子事实，不泛化为完整听牌识别或战略阻断强度。自由文本保存、不自动判理解；TV 只与作者分布对照。

“引导”和“测验”共用实际片段命令与合法的公开账本，均不展示未来答案；引导用于逐步观察，测验结束后固定结果。对手脚本固定，不随机模拟真实对手；后续牌对照是两份固定输入。

联网采集/提炼只在设计研究与过程说明中出现。运行时只查本地知识；登记一个 URL 不代表已阅读正文。36 条摘要来源自检、未独立教学审核；原文页没有提供固定文档版本，保存核对日期和小节定位，不声称保存了永久原文快照。[来源索引](research/t1-knowledge-source-index.json)逐主张列出定位。

内容使用确定性的 `fnv1a32:…:length` 检测意外改动，不是签名或安全认证。JSON 中 undefined 对象字段按实际保存形式忽略；发布版本、固定内容与 owned ID 分开。导入未知主张降为待核对；旧引用保留历史身份。未知内容版本先停用，不依据导入者自报“已审核”启动教学。

导出包含答案的备份会记录 possible-exposure；导入也保守登记可能暴露，并将未完成的导入题标辅助。旧版迁移/辅助内存模式不确证未见；可明确选择原题重做，不能借复制获得新题身份。

Hero 任意合法尺度与混合频率继续按用户要求暂缓；原范围编辑混频保留。

## 演示顺序

1. 首页进入引导课程，先走 LP-A 并保存原预测；只填三个目标组合，打开两项对照与固定研究，完成片段与总结。
2. 进入迁移题；尝试知识链接观察隔离，再显式使用提示，对比本次辅助身份与首次记录。
3. 走 LP-B，观察后门条件、两种分母与后续牌；提前复测只作为演示，不完成真实延迟项。
4. 理论知识查 `range weights`、`MDF`；分别选 HU/multiway；查“本课 AhJh 为什么下注 60%”观察证据不足。
5. 教学助手选择“提交后解释”，逐步执行三个工具；打开固定引用与出处。
6. 知识建设登记一条自写草稿，确认定位与条件后发布；内容检查器建立下一版，旧记录继续可读。
7. 复盘导入教材快照查看精确匹配；普通样例保持研究身份。最后导出备份、重置并导入，验证作品与暴露关系。
